# Уральский контекст — версия для собственного сервера

Ветка `server` содержит актуальные страницы опубликованного сайта и комплект развёртывания

- Исходники: https://github.com/ctiv656-rgb/uralsky-kontekst/tree/server
- Полная инструкция: [SERVER_GUIDE_RU.md](SERVER_GUIDE_RU.md)
- Готовое задание для ChatGPT/Codex коллеги: [PROMPT_FOR_COLLEAGUE.txt](PROMPT_FOR_COLLEAGUE.txt)
- Страницы сайта находятся в корне, изображения — в `assets/` и `brand-assets/`
- На веб-сервер выкладывается только результат `deploy/build.py`, а не весь репозиторий
- `server/` — исходники уже существующей интеграции Cloudflare + Google Sheets, отдельно от статического сайта

Схема обновлений: правки → commit/push в ветку `server` → таймер на сервере → новый релиз сайта

На FirstVDS используется HTTPS-вариант обновления раз в 5 минут: `uralsky-kontekst-http-update.timer`. Для серверов с рабочим Git-транспортом сохранён отдельный Git-вариант примерно раз в минуту. Одновременно включать оба таймера не нужно

Исходники текущего HTTPS-релиза доступны в `/opt/uralsky-kontekst/source-current`, публичные файлы — в `/opt/uralsky-kontekst/current`. Новый основной домен `ural66context.ru` подключается после регистрации и настройки DNS

Ветка `main` и старые хостинги не обновляют новый сервер автоматически
